## Steal list (UX only — not RH contracts)

Verified visually on https://usegivest.app/ (2026-10-06 browser snapshot):

1. **One sentence ritual** — “A stock, a dollar amount, a link. They claim it.”
2. **Two doors only** — big Send / Claim tiles; no markets board in the hero.
3. **Claim-first language** — “One tap. No gas. No wallet setup first.”
4. **Public proof vibe** — volume / drops / verify on-chain (we map to mode badges + DX).
5. **Sender ≠ receiver** as the product, not a transfer form.
6. **Light photo hero works for them** — we intentionally do **not** copy sand dunes; BELL stays Binance black/#F0B90B for wallet affinity.

## Do not copy

- RH Chain escrow contracts / Uniswap on RH
- Gasless relayer claims (we use Agentic Wallet + honest pending)
- Handle-based wallets (tagstock) unless Binance ships an equivalent skill
